# ADR-009 : Stratégie d'isolation interchangeable

- **Statut :** accepté (à valider par Josh)
- **Origine :** §5.1

## Contexte
Le coût du VPS ou le nombre d'entreprises peut imposer un autre schéma d'isolation.

## Décision
Une interface `TenantStrategy` cache le choix (base dédiée par défaut, schéma par entreprise en alternative) ; les modules n'en dépendent pas.

## Vérification
Tests de la stratégie (briques C2, C3).

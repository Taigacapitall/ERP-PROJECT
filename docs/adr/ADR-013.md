# ADR-013 : Fonctionnement hors ligne et synchronisation (modèle B)

- **Statut :** accepté (à valider par Josh)
- **Origine :** §5.7

## Contexte
Le fonctionnement hors ligne est requis ; la synchronisation bidirectionnelle est la partie la plus risquée.

## Décision
PWA : file d'écriture durable pour une liste fermée d'opérations (P3b), règle « le serveur gagne, revue par l'utilisateur ». Bureau (modèle B, P8) : base SQLite locale et synchronisation avec le serveur. Une facture hors ligne reste un brouillon ; le numéro légal est attribué par le serveur à l'émission. Le service worker est réservé à la PWA.

## Vérification
Tests de pannes et de rejeu (briques D7, P3b, P8).

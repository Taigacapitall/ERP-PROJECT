# ADR-004 : Aucune règle métier dans le front

- **Statut :** accepté (à valider par Josh)
- **Origine :** R4

## Contexte
Un client peut être contourné ou modifié.

## Décision
Le front valide pour l'ergonomie ; le serveur décide toujours (règles métier et autorisations).

## Vérification
Tests serveur de chaque route (briques API).

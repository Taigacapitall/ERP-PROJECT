# ADR-002 : Chargement dynamique des modules par catalogue

- **Statut :** accepté (à valider par Josh)
- **Origine :** R2

## Contexte
Les modules disponibles dépendent du catalogue de l'entreprise ; un module absent, archivé ou en échec ne doit pas empêcher le démarrage.

## Décision
Les modules sont chargés par `importlib` depuis un catalogue ; les routes d'un module ne sont importées que s'il est actif. Un module archivé n'est jamais importé.

## Vérification
Test de démarrage avec module absent et module archivé (`vorpal/plateforme/catalog.py`).

# ADR-006 : Isolation des entreprises en profondeur

- **Statut :** accepté (à valider par Josh)
- **Origine :** R6

## Contexte
Plusieurs entreprises partagent un même serveur PostgreSQL (cahier §5.1).

## Décision
Une base de contrôle (Alembic) et une base PostgreSQL par entreprise, avec un rôle PostgreSQL dédié, un contexte dédié et des identifiants chiffrés (AES-256-GCM, clé maître hors dépôt).

## Vérification
Tests d'accès croisés (briques C2, C3, D2).

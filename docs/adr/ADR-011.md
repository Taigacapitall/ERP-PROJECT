# ADR-011 : Comptabilité native retenue

- **Statut :** accepté (à valider par Josh)
- **Origine :** Décision v1.1 (§1.1)

## Contexte
Deux voies existaient : adaptateur Odoo et module natif `vorpal/modules/comptabilite/` (51 tests, branché à Ventes et DGI).

## Décision
Le module natif est la voie retenue. L'adaptateur Odoo et `odoo_addons` sont archivés dans `legacy/` (hors paquet, hors CI, sans modification), brique A1.

## Vérification
`legacy/README.md` ; `pyproject.toml` n'inclut que `vorpal*`.

# ADR-003 : Ajouts seulement sur le Core et les modules existants

- **Statut :** accepté (à valider par Josh)
- **Origine :** R3

## Contexte
Le Core v1 est protégé ; les modules existants sont validés par des tests.

## Décision
On ajoute (fichiers, exports, paramètres optionnels, migrations additives) ; on ne renomme, ne supprime et ne change aucun comportement. Toute modification du Core exige l'autorisation explicite de Josh.

## Vérification
`scripts/check_additive_changes.py` (CI) : refuse toute ligne supprimée par rapport à `core-v1`.

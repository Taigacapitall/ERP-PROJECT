# ADR-001 : La Plateforme est une couche hôte

- **Statut :** accepté (à valider par Josh)
- **Origine :** R1

## Contexte
La Plateforme (`vorpal/plateforme/`) assemble les modules ; ce n'est pas un module métier. Elle vit à côté de `vorpal/core/` et `vorpal/modules/`.

## Décision
Aucun module (ni le Core) n'importe `vorpal.plateforme`. La Plateforme n'importe que le Core et charge les modules dynamiquement.

## Vérification
Test d'architecture `tests/plateforme/test_architecture.py` (analyse des imports).

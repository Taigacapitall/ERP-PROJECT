# ADR-012 : Une API, plusieurs clients

- **Statut :** accepté (à valider par Josh)
- **Origine :** R8

## Contexte
La PWA et l'application de bureau doivent se comporter de façon identique.

## Décision
Les deux clients utilisent la même API v1. La logique hors ligne (file d'écriture, cache, synchronisation) vit dans un paquet TypeScript pur `web/packages/offline-core`, sans dépendance au DOM ni au service worker.

## Vérification
Test d'architecture front : `offline-core` n'importe ni DOM ni service worker.

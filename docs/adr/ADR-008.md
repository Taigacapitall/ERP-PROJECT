# ADR-008 : Les modules ne s'importent pas entre eux

- **Statut :** accepté (à valider par Josh)
- **Origine :** Règle du Core

## Contexte
Des dépendances directes entre modules rendraient le chargement par catalogue impossible.

## Décision
Un module n'importe jamais un autre module ; ils communiquent par le Core : contrats, services, événements.

## Vérification
Test d'architecture (aucun import `vorpal.modules.<autre>` depuis un module).
